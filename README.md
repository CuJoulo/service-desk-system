# Програмна система Service-desk для автоматизації бізнес-процесів IT департаменту

## 1. Призначення системи
Автоматизація процесів реєстрації, класифікації, обробки звернень користувачів до ІТ-підрозділу підприємства та контроль дотримання угод про рівень обслуговування (SLA).

## 2. Короткий опис функціональності
- Реєстрація, маршрутизація та облік тікетів (інцидентів і запитів);
- Автоматичний розрахунок дедлайнів виконання робіт за регламентами SLA;
- Внутрішня комунікація в заявках через коментарі;
- Автоматичні email-сповіщення про зміну статусів заявок;
- Формування аналітичних звітів та дашбордів продуктивності.

## 3. Використані технології
- Frontend: React, HTML5, CSS3
- Backend: Node.js, Express, REST API
- База даних: PostgreSQL
- Сповіщення: SMTP

## 4. Спосіб запуску проєкту
1. Склонувати репозиторій: git clone <URL>
2. Встановити залежності: npm install
3. Запустити сервер: npm start
